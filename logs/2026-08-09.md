## 🧠 Challenge of the Day

### Factorial

**Difficulty:** Easy
**Topic:** Recursion

**Problem:**

Compute n! (n factorial) — the product of all positive integers up to n. Note: 0! = 1.

**Example:**

```
Input: 5
Output: 120  (5 × 4 × 3 × 2 × 1)
```

**Hint:**

Either recursively (n × factorial(n-1), base case 0! = 1) or iteratively with a running product.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
// Recursive
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}

// Iterative (no stack overflow risk)
function factorialIter(n) {
  let result = 1;
  for (let i = 2; i <= n; i++) result *= i;
  return result;
}
```

**Explanation:** Recursion is elegant but for large n, iterative is safer (JavaScript has a call stack limit around 10,000).

## 💡 Tip of the Day

**Use `Array.from()` with a mapper for clean transforms**

`Array.from()` accepts a map function as its second argument — cleaner than `.map()` after `.fill()`.

```js
// ❌ Verbose
const zeros = new Array(5).fill(0);
const squares = zeros.map((_, i) => i * i);

// ✅ Clean
const squares = Array.from({ length: 5 }, (_, i) => i * i);
// [0, 1, 4, 9, 16]
```
