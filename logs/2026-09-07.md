## 🧠 Challenge of the Day

### Palindrome Check

**Difficulty:** Easy
**Topic:** Strings

**Problem:**

Check if a string is a palindrome, ignoring case, spaces, and non-alphanumeric characters.

**Example:**

```
Input: "A man, a plan, a canal: Panama"
Output: true
```

**Hint:**

Sanitize the string first (lowercase, strip non-alphanumeric), then use two pointers from both ends.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
function isPalindrome(str) {
  const clean = str.toLowerCase().replace(/[^a-z0-9]/g, '');
  let left = 0, right = clean.length - 1;
  while (left < right) {
    if (clean[left] !== clean[right]) return false;
    left++;
    right--;
  }
  return true;
}
```

**Explanation:** Cleaning the string first makes the comparison straightforward. Two-pointer avoids creating a reversed copy.

## 💡 Tip of the Day

**Tagged template literals for safe HTML**

Template literals can be tagged with a function that pre-processes parts:

```js
function html(strings, ...values) {
  return strings.reduce((acc, str, i) => {
    const val = values[i] ?? '';
    return acc + str + String(val).replace(/[<>&]/g, c =>
      ({ '<': '&lt;', '>': '&gt;', '&': '&amp;' }[c]));
  }, '');
}

const userInput = '<script>alert(1)</script>';
const safe = html`<div>${userInput}</div>`;
// <div>&lt;script&gt;alert(1)&lt;/script&gt;</div>
```

This is how lit-html and other libraries escape user content safely.
