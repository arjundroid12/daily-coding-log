## 🧠 Challenge of the Day

### Sum of Digits

**Difficulty:** Easy
**Topic:** Math / Loops

**Problem:**

Given a non-negative integer, return the sum of its digits.

**Example:**

```
Input: 12345
Output: 15  (1 + 2 + 3 + 4 + 5)
```

**Hint:**

Either convert to string and iterate, or repeatedly mod 10 + divide by 10.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
// String approach
function sumDigits(n) {
  return String(n).split('').reduce((sum, d) => sum + Number(d), 0);
}

// Math approach (no string conversion)
function sumDigitsMath(n) {
  let sum = 0;
  while (n > 0) {
    sum += n % 10;
    n = Math.floor(n / 10);
  }
  return sum;
}
```

**Explanation:** The math approach is faster (no string allocation) and works in any language. String approach is more readable.

## 💡 Tip of the Day

**Avoid `forEach` when you need to `break` or `return`**

`forEach` doesn't support `break` or early return — use `for...of` instead:

```js
// ❌ Can't break out of forEach
arr.forEach(item => {
  if (item === target) return;  // doesn't do what you think!
  console.log(item);
});

// ✅ for...of supports break
for (const item of arr) {
  if (item === target) break;
  console.log(item);
}
```

`.some()` and `.every()` also short-circuit — useful for early-exit searches.
