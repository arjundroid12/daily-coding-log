## 🧠 Challenge of the Day

### Factorial

**Difficulty:** Easy
**Topic:** Recursion

**Problem:**

Compute n! (n factorial) — the product of all positive integers up to n. Note: 0! = 1.

**Example:**

```
Input: 5
Output: 120  (5 × 4 × 3 × 2 × 1)
```

**Hint:**

Either recursively (n × factorial(n-1), base case 0! = 1) or iteratively with a running product.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
// Recursive
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}

// Iterative (no stack overflow risk)
function factorialIter(n) {
  let result = 1;
  for (let i = 2; i <= n; i++) result *= i;
  return result;
}
```

**Explanation:** Recursion is elegant but for large n, iterative is safer (JavaScript has a call stack limit around 10,000).

</details>

## 💡 Tip of the Day

**Bit-shift for integer division by powers of 2**

Bit-shifting is faster than `Math.floor(n / 2)`:

```js
Math.floor(7 / 2);   // 3
7 >> 1;              // 3 (same result, faster)

Math.floor(7 / 4);   // 1
7 >> 2;              // 1
```

Only works for positive integers and divisors that are powers of 2. Common in binary search midpoints.
