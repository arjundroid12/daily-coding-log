## 🧠 Challenge of the Day

### Remove Duplicates from Array

**Difficulty:** Easy
**Topic:** Arrays / Sets

**Problem:**

Return a new array with duplicates removed, preserving the order of first occurrence.

**Example:**

```
Input: [1, 2, 2, 3, 4, 4, 5]
Output: [1, 2, 3, 4, 5]
```

**Hint:**

Use a Set to track seen elements, or just convert to Set and back to array.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
// Simple Set approach
function dedupe(arr) {
  return [...new Set(arr)];
}

// Preserve order, filter manually (for objects you can't put in Set)
function dedupeBy(arr, keyFn = (x) => x) {
  const seen = new Set();
  return arr.filter((item) => {
    const key = keyFn(item);
    if (seen.has(key)) return false;
    seen.add(key);
    return true;
  });
}
```

**Explanation:** Sets guarantee uniqueness. The second approach is more flexible — works for objects via a key function.

## 💡 Tip of the Day

**Tagged template literals for safe HTML**

Template literals can be tagged with a function that pre-processes parts:

```js
function html(strings, ...values) {
  return strings.reduce((acc, str, i) => {
    const val = values[i] ?? '';
    return acc + str + String(val).replace(/[<>&]/g, c =>
      ({ '<': '&lt;', '>': '&gt;', '&': '&amp;' }[c]));
  }, '');
}

const userInput = '<script>alert(1)</script>';
const safe = html`<div>${userInput}</div>`;
// <div>&lt;script&gt;alert(1)&lt;/script&gt;</div>
```

This is how lit-html and other libraries escape user content safely.
