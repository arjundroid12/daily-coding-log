## 🧠 Challenge of the Day

### Anagram Check

**Difficulty:** Easy
**Topic:** Strings / Sorting

**Problem:**

Check if two strings are anagrams (contain the same characters with the same frequencies).

**Example:**

```
Input: "listen", "silent"
Output: true

Input: "hello", "world"
Output: false
```

**Hint:**

Sort both strings and compare. Or, count character frequencies with a Map.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
// Approach 1: Sort and compare (concise)
function isAnagram(a, b) {
  const norm = (s) => s.toLowerCase().split('').sort().join('');
  return norm(a) === norm(b);
}

// Approach 2: Frequency counter (faster for long strings)
function isAnagramFast(a, b) {
  if (a.length !== b.length) return false;
  const counts = new Map();
  for (const ch of a.toLowerCase()) {
    counts.set(ch, (counts.get(ch) || 0) + 1);
  }
  for (const ch of b.toLowerCase()) {
    if (!counts.has(ch)) return false;
    counts.set(ch, counts.get(ch) - 1);
    if (counts.get(ch) < 0) return false;
  }
  return true;
}
```

**Explanation:** Sorting is O(n log n) but very concise. Frequency counting is O(n) but more code. Pick based on input size.

## 💡 Tip of the Day

**Use `structuredClone()` for deep copies**

Stop writing `JSON.parse(JSON.stringify(obj))` — it loses Dates, Maps, Sets, undefined, functions, and chokes on circular refs.

Modern browsers and Node 17+ have `structuredClone()`:

```js
const clone = structuredClone(original);
// Handles Dates, Maps, Sets, circular refs, typed arrays, etc.
```
