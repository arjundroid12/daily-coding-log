## 🧠 Challenge of the Day

### Sum of Digits

**Difficulty:** Easy
**Topic:** Math / Loops

**Problem:**

Given a non-negative integer, return the sum of its digits.

**Example:**

```
Input: 12345
Output: 15  (1 + 2 + 3 + 4 + 5)
```

**Hint:**

Either convert to string and iterate, or repeatedly mod 10 + divide by 10.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
// String approach
function sumDigits(n) {
  return String(n).split('').reduce((sum, d) => sum + Number(d), 0);
}

// Math approach (no string conversion)
function sumDigitsMath(n) {
  let sum = 0;
  while (n > 0) {
    sum += n % 10;
    n = Math.floor(n / 10);
  }
  return sum;
}
```

**Explanation:** The math approach is faster (no string allocation) and works in any language. String approach is more readable.

## 💡 Tip of the Day

**Tagged template literals for safe HTML**

Template literals can be tagged with a function that pre-processes parts:

```js
function html(strings, ...values) {
  return strings.reduce((acc, str, i) => {
    const val = values[i] ?? '';
    return acc + str + String(val).replace(/[<>&]/g, c =>
      ({ '<': '&lt;', '>': '&gt;', '&': '&amp;' }[c]));
  }, '');
}

const userInput = '<script>alert(1)</script>';
const safe = html`<div>${userInput}</div>`;
// <div>&lt;script&gt;alert(1)&lt;/script&gt;</div>
```

This is how lit-html and other libraries escape user content safely.
