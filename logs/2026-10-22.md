## 🧠 Challenge of the Day

### Count Vowels

**Difficulty:** Easy
**Topic:** Strings / Regex

**Problem:**

Count the number of vowels (a, e, i, o, u) in a string. Case-insensitive.

**Example:**

```
Input: "Hello World"
Output: 3  (e, o, o)
```

**Hint:**

Match against a vowel regex, or iterate and check membership in a Set.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
// Regex approach
function countVowels(str) {
  return (str.match(/[aeiou]/gi) || []).length;
}

// Set approach (faster for very long strings)
function countVowelsSet(str) {
  const vowels = new Set(['a','e','i','o','u']);
  let count = 0;
  for (const ch of str.toLowerCase()) {
    if (vowels.has(ch)) count++;
  }
  return count;
}
```

**Explanation:** Two valid approaches. Regex is concise; Set is faster because Set.has() is O(1) and there's no regex compilation.

</details>

## 💡 Tip of the Day

**Use `Intl` APIs for locale-aware formatting**

Stop hardcoding date/number formats. Use `Intl`:

```js
// Currency
new Intl.NumberFormat('en-IN', { style: 'currency', currency: 'INR' })
  .format(1234567.89);  // '₹12,34,567.89' (Indian grouping)

// Dates
new Intl.DateTimeFormat('en-IN', { dateStyle: 'full' })
  .format(new Date());  // 'Monday, 29 June 2026'

// Relative time
new Intl.RelativeTimeFormat('en', { style: 'short' })
  .format(-1, 'day');  // 'yesterday'
```
