## 🧠 Challenge of the Day

### Find Maximum in Array

**Difficulty:** Easy
**Topic:** Arrays

**Problem:**

Find the maximum value in an array without using `Math.max()` or `.sort()`.

**Example:**

```
Input: [3, 1, 7, 2, 9, 4]
Output: 9
```

**Hint:**

Initialize with the first element, then iterate and update when you find something bigger.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
function findMax(arr) {
  if (arr.length === 0) return undefined;
  let max = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
  }
  return max;
}

// O(n) time, O(1) space
```

**Explanation:** Linear scan is optimal — you can't find the max without looking at every element at least once.

## 💡 Tip of the Day

**Tagged template literals for safe HTML**

Template literals can be tagged with a function that pre-processes parts:

```js
function html(strings, ...values) {
  return strings.reduce((acc, str, i) => {
    const val = values[i] ?? '';
    return acc + str + String(val).replace(/[<>&]/g, c =>
      ({ '<': '&lt;', '>': '&gt;', '&': '&amp;' }[c]));
  }, '');
}

const userInput = '<script>alert(1)</script>';
const safe = html`<div>${userInput}</div>`;
// <div>&lt;script&gt;alert(1)&lt;/script&gt;</div>
```

This is how lit-html and other libraries escape user content safely.
