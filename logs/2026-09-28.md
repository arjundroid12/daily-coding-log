## 🧠 Challenge of the Day

### Sum of Digits

**Difficulty:** Easy
**Topic:** Math / Loops

**Problem:**

Given a non-negative integer, return the sum of its digits.

**Example:**

```
Input: 12345
Output: 15  (1 + 2 + 3 + 4 + 5)
```

**Hint:**

Either convert to string and iterate, or repeatedly mod 10 + divide by 10.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
// String approach
function sumDigits(n) {
  return String(n).split('').reduce((sum, d) => sum + Number(d), 0);
}

// Math approach (no string conversion)
function sumDigitsMath(n) {
  let sum = 0;
  while (n > 0) {
    sum += n % 10;
    n = Math.floor(n / 10);
  }
  return sum;
}
```

**Explanation:** The math approach is faster (no string allocation) and works in any language. String approach is more readable.

</details>

## 💡 Tip of the Day

**Use `Number.isFinite()` not `isFinite()`**

Global `isFinite()` coerces — `isFinite('42')` returns `true`. `Number.isFinite()` doesn't.

```js
isFinite('42');          // true (coerces string to number)
Number.isFinite('42');   // false (strict type check)
Number.isFinite(42);     // true
Number.isFinite(Infinity); // false
```
