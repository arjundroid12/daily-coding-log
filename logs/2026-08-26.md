## 🧠 Challenge of the Day

### Count Character Frequencies

**Difficulty:** Easy
**Topic:** Strings / Hash Maps

**Problem:**

Return an object mapping each character in a string to its frequency. Case-sensitive.

**Example:**

```
Input: "hello"
Output: { h: 1, e: 1, l: 2, o: 1 }
```

**Hint:**

Iterate and use a plain object or Map. Initialize missing keys to 0 then increment, or use nullish coalescing.

<details>
<summary>🔍 Reveal solution</summary>

```javascript
function charFreq(str) {
  const freq = {};
  for (const ch of str) {
    freq[ch] = (freq[ch] || 0) + 1;
  }
  return freq;
}

// Map version (works when keys aren't strings)
function charFreqMap(str) {
  const freq = new Map();
  for (const ch of str) {
    freq.set(ch, (freq.get(ch) || 0) + 1);
  }
  return freq;
}
```

**Explanation:** Frequency counters are a fundamental pattern — used in anagram checks, compression, stats, etc.

## 💡 Tip of the Day

**Use `Array.prototype.findLast()` and `.findLastIndex()`**

ES2023 added `findLast` / `findLastIndex` — find the LAST matching element without reversing:

```js
const arr = [1, 2, 3, 4, 5, 4, 3];

// Old way
[...arr].reverse().find(x => x === 4);  // mutates copy, awkward

// New way (ES2023)
arr.findLast(x => x === 4);  // 4 (the second occurrence)
arr.findLastIndex(x => x === 4);  // 5
```
